# Voa Daqui

Os voos mais baratos de Lisboa, Porto e Faro, ida e volta para escapadinhas de 2 a 4 noites nas próximas 8 semanas, e a **Pechincha do dia**: a ligação que hoje está muito abaixo do preço habitual.

- Site: https://voadaqui.pt (`index.html`) (estático, lê `data/data.json`)
- Dados: atualizados de hora a hora (7h–23h) a partir do Kiwi.com (ver [UPDATE.md](UPDATE.md))
- Gerador: `build.py` (Python 3, sem dependências); `og.py` gera a imagem de partilha `og.png`
- Alojamento do Voo + hotel: `hotels.txt` (Booking.com, às 7h)
- Contador de visitas: escrever o código GoatCounter em `assets/config.js`
- Página Sobre e privacidade: `sobre.html`

Preços por pessoa, só com mochila pequena. Mudam a toda a hora: confirma sempre no site da reserva antes de pagar.
